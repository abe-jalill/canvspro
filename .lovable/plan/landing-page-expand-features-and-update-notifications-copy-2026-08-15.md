# Landing page: expand features and update notifications copy

Update the public landing page (`src/routes/index.tsx`) to better showcase the full product and reflect the customizable notification model.

## What will change

- Update the "Reminders that matter" feature card to say users can customize **when** and **what** they are notified about.
- Add a **Grade calculator** feature card in the "What you get" grid.
- Expand the "What you get" grid to **8 feature cards** plus one final card that says **"many more"** and lists the remaining capabilities.
- Keep the existing Grade calculator link in the "Free tools while you're here" section.
- Add Lucide icons for the new cards, matching the existing monochrome style.
- Preserve the existing glass-card layout, dark theme, and mobile-first grid.

## Proposed 8 feature cards

1. A homepage you arrange
2. Live grades, no clicking
3. Assignments that stay sorted
4. Calendar and class schedule
5. Focus windows
6. Custom notifications — choose when and what
7. Grade calculator — weighted grades + final-exam targets
8. Workload heatmap — see your busy days at a glance

## "Many more" card contents

- Announcements in one place
- Class nicknames
- Syllabus quick-view
- Grade trend arrows
- .ICS calendar export
- Dark / light mode
- Mobile-first layout

## No other changes

- No new routes, no backend changes, no billing or auth changes.
